# Provenance

bemkit was developed privately from July 2026 by Martin Pollow, and first
published under GPL-3.0.

**Commit dates in this repository are not independent evidence.** Git lets an
author set any date, and this history was rewritten on 2026-11-03, before first
publication, to change the contact email, adopt GPL-3.0 in every commit, and move
private studies out. The dates are carried over from the original commits. The
external date is the first public push. Commit messages and some code comments
still name those private studies.

The files below were not published. They are the unmodified originals. Each
SHA-256 fixes one exact file, so anyone given that file later can confirm it is
the one fingerprinted here, and that it therefore existed no later than the first
public commit containing this file.
